<h1 align="center">42 Tokyo C Piscine</h1>

This repository contains my **42 Tokyo C Piscine** projects from 2026, including the Shell modules, C modules, weekend Rush projects, and BSQ.

## About 42

[42](https://42.fr/) is a peer-to-peer software engineering school built around project-based learning. Instead of traditional lectures, students learn by solving progressively harder projects, researching independently, collaborating with peers, and reviewing each other's work.

## About the C Piscine

The **C Piscine** is an intensive selection and learning period centered on C, the shell, Git, problem solving, peer evaluation, and teamwork. The C modules progress from basic output and pointers to memory allocation, data structures, recursion, and larger programs. Weekend **Rush** projects are completed in teams, while **BSQ** is a larger standalone C project focused on parsing, memory management, and algorithms.
