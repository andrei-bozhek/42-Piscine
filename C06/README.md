# C06

Small programs built around `argc`/`argv`: printing the program name, arguments, reverse order, and ASCII sorting.

**Subject:** [C06_subject.pdf](./C06_subject.pdf)

## Exercises

|:---:|:---|
| [ex00](./ex00/) | Print the name used to launch the program |
| [ex01](./ex01/) | Print command-line arguments in their original order |
| [ex02](./ex02/) | Print command-line arguments in reverse order |
| [ex03](./ex03/) | Sort command-line arguments lexicographically and print them |
