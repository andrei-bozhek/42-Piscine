# Shell00

Introduction to Unix files, permissions, timestamps, links, SSH keys, Git commands, `diff`/`patch`, `find`, and magic files.

[← Back to main README](../README.md) · [Shell00_subject.pdf](./Shell00_subject.pdf)

## Exercises

| Exercise | Description |
|:---:|:---|
| [ex00](./ex00/) | Create a file that outputs `Z` followed by a newline |
| [ex01](./ex01/) | Create a file with specific permissions, size and modification time, then archive it |
| [ex02](./ex02/) | Reproduce a predefined set of files, directories, permissions, links and timestamps |
| [ex03](./ex03/) | Generate an Ed25519 SSH key and register its public key |
| [ex04](./ex04/) | Build an `ls` command with modification-time sorting, comma-separated output and directory suffixes |
| [ex05](./ex05/) | Display the hashes of the last five Git commits |
| [ex06](./ex06/) | List files currently ignored by Git |
| [ex07](./ex07/) | Reconstruct a target file by applying a patch/diff |
| [ex08](./ex08/) | Find, display and delete temporary files matching specific filename patterns |
| [ex09](./ex09/) | Create a magic file that identifies files containing `42` at the 42nd byte |
