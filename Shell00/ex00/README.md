# ex00 - Z

[Subject PDF](../Shell00_subject.pdf)

## Task

Create a file named `z` whose contents are exactly `Z` followed by a newline.

## Submission

| Requirement | Value |
|---|---|
| Turn-in directory | `ex00/` |
| File to turn in | `z` |
| Allowed functions | None |

## How it was done

The file contains only `Z\n`. Running `cat z` therefore prints the required character and newline.
