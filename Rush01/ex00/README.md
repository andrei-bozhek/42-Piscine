# ex00 - Rush01

[Subject PDF](../Rush01_subject.pdf)

## Task

Solve a 4x4 Skyscrapers grid from exactly 16 clues (`1` to `4`) separated by spaces. Each row/column must contain heights 1-4 exactly once; print the first solution or `Error`.
